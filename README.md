# Meu Treino

App de treino de 12 semanas (3 fases, treinos A–E) com animação dos exercícios, registro de carga e repetições, timer de descanso, gráficos de evolução, fila automática e backup.

- `www/`: o app (HTML/JS, funciona offline como PWA)
- Cada push na branch `main` gera o APK (aba **Releases**) e publica a versão web no **GitHub Pages**.

Imagens dos exercícios: [free-exercise-db](https://github.com/yuhonas/free-exercise-db) (domínio público).
